🚀 INSTALACIÓN Y CONFIGURACIÓN
================================================================================

REQUISITOS
  Python: 3.8+
  LLM: Acceso a Claude (o compatible con Anthropic API)
  pip: 21+

PASOS
  1. Descarga los 4 archivos de código
     - test_scenario_agent_a.py
     - test_scenario_agent_b.py
     - test_scenario_agent_c.py
     - ejemplo_uso_agentes_test.py

  2. Configura variables de entorno
     export LLM_BASE_URL="http://localhost:8082/v1/messages"
     export LLM_API_KEY="tu_api_key"
     export LLM_MODEL="claude-3-5-sonnet-20241022"

  3. (Opcional) Instala chromadb para Opción C
     pip install chromadb

  4. Verifica
     python -c "from test_scenario_agent_b import TestScenarioGenerator; print('✓ OK')"

  5. ¡Listo!
     python ejemplo_uso_agentes_test.py --opcion todas
