# 00 - Caso Base: TravelOps IA

## Historia

Una agencia recibe consultas como:
"¿Conviene viajar a Medellín la próxima semana con presupuesto medio y plan familiar?"

El sistema debe:

1. entender intención
2. obtener contexto (clima, políticas, restricciones)
3. proponer plan de viaje razonado
4. justificar recomendaciones

## Objetivo de aprendizaje

Definir visión, límites y métricas antes de construir agentes.

## Entregables

- Documento breve con:
  - alcance funcional
  - no alcance
  - riesgos
  - métricas (calidad, latencia, costo)

## Criterios de éxito

- Caso de uso y límites claros
- Métricas concretas y medibles
- Lista inicial de herramientas externas
