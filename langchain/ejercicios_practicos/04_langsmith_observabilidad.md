# 04 - Observabilidad con LangSmith

## Objetivo

Activar trazas y evaluación para mejorar calidad en ciclos cortos.

## Qué agregar al proyecto

- tracing de cadenas/grafos
- dataset de evaluación inicial
- métricas de calidad y costo

## Tareas

1. Instrumentar ejecución completa
2. Crear dataset con casos reales y casos límite
3. Definir criterios de evaluación semántica
4. Comparar dos variantes de prompt

## Escenarios de prueba

- consulta clara
- consulta ambigua
- consulta adversarial (prompt injection simple)

## Criterios de éxito

- trazas visibles por ejecución
- resultados comparables entre variantes
- decisión documentada de qué versión conservar
