# Ruta de Ejercicios Prácticos (Incremental)

Esta ruta usa **un solo caso** y en cada ejercicio agrega capacidades nuevas.

## Caso único: TravelOps IA

Construiremos un sistema de agentes para una agencia de viajes que:

- entiende pedidos del cliente
- consulta clima y políticas
- propone itinerarios
- coordina 2–3 agentes especializados
- integra herramientas vía MCP
